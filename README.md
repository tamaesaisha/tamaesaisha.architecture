# Tamae Saisha Reddy — architecture portfolio

Live site: https://tamaesaisha.github.io/tamaesaisha.architecture/

Built with Jekyll and hosted on GitHub Pages. Content is edited in Pages CMS
(https://app.pagescms.org). See SETUP.md for setup and editing instructions.

- `_projects/` — one file per project
- `_data/about.yml` — About page
- `_data/settings.yml` — name, contact details, portfolio PDF
- `assets/uploads/` — images and PDFs
- `.pages.yml` — what the Pages CMS editor shows
